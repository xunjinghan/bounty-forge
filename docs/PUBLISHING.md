# 发布清单 · 什么能进公开仓库

本项目是**公开**仓库，但同一套工作流也会产出更敏感的内部产物（记忆、完整证据、成本台账、
含个人信息的日志）。发布前请逐条对照。

## 可以公开

- 已脱敏的漏洞报告（无真实目标域名/IP、无他人数据）
- 方法论、避坑手册、检查清单、模板
- 本地靶场（DVWA / bWAPP / Vulhub / 自研靶场）的复现步骤与结果
- nuclei 模板 / 只读检测脚本（默认非破坏性）
- 工具链与流程说明

## 不要公开

- 任何真实凭据：API Key、Token、Cookie、口令、私钥
- 真实目标的响应正文、数据库内容、用户数据
- 第三方平台的账号标识（openid / uid / 手机号 / 邮箱）
- 内部协作记录（Agent 会话、IM 记录、待办看板、成本台账）
- 可反推个人身份的绝对路径与设备名

## 发布前自查（30 秒）

```bash
# 凭据与个人路径
grep -rInE 'github_pat_|ghp_[A-Za-z0-9]{30,}|sk-[A-Za-z0-9]{32,}|AIza[A-Za-z0-9_-]{30,}' \
  --exclude-dir=.git . && echo "命中，先脱敏" || echo "无命中"
```

## 与私有归档的关系

完整内部产物（记忆、全量证据、台账）保存在私有归档中；公开仓库只收"可展示、可复用、
不含他人数据"的部分。内部→公开的搬运请**逐条挑选**，不要整目录同步。
