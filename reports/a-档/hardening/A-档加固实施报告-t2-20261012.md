## A3 · CSRF token 从 HMAC 派生改为会话内随机值

### 改前（`app.py.loop1-original:356-368`）

```python
    # 第七轮修复#5：CSRF token = HMAC-SHA256(SECRET_KEY, session_token)
    def csrf_token(self):
        tok = self._session_token()
        if not tok:
            return ""
        return hmac.new(SECRET_KEY.encode(), tok.encode(),
                        hashlib.sha256).hexdigest()
```

根因：token 完全由 `(SECRET_KEY, session_token)` 决定，两者都在攻击者可达范围内（`/debug` 泄露 `SECRET_KEY`，见 VER-03）→ 可离线复现。

### 改后（`app.py:374-407`）

```python
    # Loop2 A3 修复：CSRF token 改为服务端会话内随机值（secrets.token_urlsafe），
    # 不再由 HMAC(SECRET_KEY, session_token) 派生——即便 SECRET_KEY 泄露，
    # 也无法由会话 token 离线推导出页面 token。
    def csrf_token(self):
        tok = self._session_token()
        if not tok:
            return ""
        conn = get_db()
        try:
            row = conn.execute("SELECT csrf_token FROM sessions WHERE token=?", (tok,)).fetchone()
        finally:
            conn.close()
        if row is None:
            return ""
        stored = row["csrf_token"]
        if stored:
            return stored
        # 兜底：老会话行尚无 csrf_token 时补齐（一次性）
        fresh = make_token()
        conn = get_db()
        try:
            conn.execute("UPDATE sessions SET csrf_token=? WHERE token=?", (fresh, tok))
            conn.commit()
        finally:
            conn.close()
        return fresh
```

配套改动：

- `SCHEMA.sessions` 增加 `csrf_token TEXT`（`app.py:111`，改前 `:105-110` 只有 4 列）
- `create_session` 生成并落库（`app.py:236-245`，改前 `:220-228`）：`csrf = make_token()` → `INSERT ... csrf_token`
- 新增 `migrate_schema()`（`app.py:206-215`）并在 `ensure_initialized()`（`:225`）调用，给已存在的 `lab.db` 幂等补列——**没有删库重建**，老数据保留

```python
    def reset_endpoint(self):
        # ① 来源必须回环
        peer = self.client_address[0]
        if peer not in ("127.0.0.1", "::1"):
            self.html(403, "<h1>403</h1><p>仅允许本机回环访问。</p>")
            return
        # ② 仅允许 POST（HEAD/GET 一律 405，爬虫与 <img> 不再触发重建）
        if self.command != "POST":
            self.html(405, page("405", "<h1>方法不允许</h1><p>复位接口仅接受 POST 请求，且需携带 confirm=RESET。</p>"))
            return
        # ③ 二次确认参数
        path, form = self.form()
        if form.get("confirm", "") != "RESET":
            self.html(400, page("400", "<h1>缺少二次确认</h1><p>POST 体需包含 confirm=RESET。</p>"))
            return
        # ④ 审计日志（不可逆操作必须留痕）
        try:
            with open(os.path.join(BASE_DIR, "reset-audit.log"), "a", encoding="utf-8") as fh:
                fh.write(f"[{time.strftime('%Y-%m-%d %H:%M:%S')}] RESET peer={peer} ua={self.headers.get('User-Agent','')}\n")
        except Exception:
            pass
        reset_database()
        self.html(200, page("reset", "<h1>已重置</h1><p>数据库、上传目录已恢复初始状态。</p>..."))
```
